# Student Performance Prediction System
## UI Design

## 1. Home Page

The home page will introduce the Student Performance
Prediction System.

It will contain:

- Project title
- Short description
- Purpose of the system
- Button to start a prediction
- Button to view prediction history

## 2. Prediction Page

The prediction page will contain a form for entering
student-related information.

The initial fields will be:

1. Weekly Study Hours
2. Seminar/Conference Attendance
3. Class Attendance
4. Note-taking
5. Listening in Class
6. Discussion
7. Previous GPA
8. Expected Graduation GPA

The form will use appropriate input controls such as
dropdown menus or selection fields where applicable.

## 3. Prediction Result

After submitting the form, the system will display:

- Predicted performance grade
- A clear result message
- Option to make another prediction

## 4. Prediction History

The prediction history page will display relevant
previous prediction records.

It may contain:

- Student name/identifier
- Predicted grade
- Prediction date and time

## 5. Dashboard

The dashboard will provide basic information and
visualisation related to prediction records.

## 6. Design Principles

The interface will be:

- Simple
- Clean
- Easy to navigate
- Beginner-friendly
- Suitable for desktop use
- Consistent across pages

## 7. Technologies

The interface will be developed using:

- HTML5
- CSS3
- JavaScript

Flask will be used to connect the interface with
the backend functionality.
