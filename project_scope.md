# Student Performance Prediction System
## Final Project Scope

## 1. Core Functionality

The system will predict a student's academic performance
using a supervised machine learning classification model.

The user will enter selected student-related attributes
through a web interface.

The system will process the input and generate a predicted
performance grade/category.

---

## 2. Machine Learning Features

The project will include:

- Dataset collection and understanding
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- Training of multiple classification models
- Model evaluation
- Model comparison
- Selection of a suitable final model
- Saving the trained model
- Using the trained model for new predictions

---

## 3. Web Application Features

The application will include:

### Home Page
Provides an introduction to the Student Performance
Prediction System.

### Prediction Form
Allows the user to enter the required student attributes.

### Prediction Result
Displays the predicted academic performance.

### Dashboard
Displays basic information and visualisations related
to the prediction system.

### Prediction History
Displays relevant previously stored prediction records.

---

## 4. Database Features

MySQL will be used for storing relevant application data.

The database will support:

- Student information storage
- Prediction record storage
- Prediction result storage
- Retrieval of previous prediction records

The exact tables and columns will be finalized during
the database-design phase.

---

## 5. Technologies

The project will use:

- Python

- Scikit-learn

- HTML
- CSS
- JavaScript
- MySQL
- Matplotlib
- Seaborn
- Git
- GitHub

---

## 6. Dataset

The project will use the UCI Higher Education Students
Performance Evaluation dataset.

The dataset will be inspected and analysed before the
final prediction features are selected.

The original target variable, OUTPUT Grade, will initially
be retained for the prediction task.

---

## 7. Project Boundaries

The first version of the project will NOT include:

- Mobile application
- React frontend
- Flutter application
- Deep learning
- Chatbot
- Large Language Model
- RAG system
- Facial recognition
- Real-time college ERP integration
- Automated academic decision-making

These features may be considered as future extensions
but are outside the scope of the current mini project.

---

## 8. Final Deliverable

The final deliverable will be a working web-based
Student Performance Prediction System containing:

1. Trained machine learning model
2. Flask backend
3. HTML/CSS/JavaScript frontend
4. MySQL database
5. Prediction functionality
6. Basic dashboard/visualisation
7. Prediction history
8. Testing and evaluation results
9. Project documentation
10. Presentation and live demonstration
