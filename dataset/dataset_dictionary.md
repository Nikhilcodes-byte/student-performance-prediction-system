# Dataset Dictionary

## Dataset

Higher Education Students Performance Evaluation

## Source

UCI Machine Learning Repository

## Records

145

## Target

GRADE

## Target Description

The GRADE column represents the student's output academic
performance category.

0 = Fail
1 = DD
2 = DC
3 = CC
4 = CB
5 = BB
6 = BA
7 = AA

## Features

1. Student Age
2. Sex
3. Graduated high-school type
4. Scholarship type
5. Additional work
6. Regular artistic or sports activity
7. Partner status
8. Total salary
9. Transportation to university
10. Accommodation type
11. Mother's education
12. Father's education
13. Number of sisters/brothers
14. Parental status
15. Mother's occupation
16. Father's occupation
17. Weekly study hours
18. Non-scientific reading frequency
19. Scientific reading frequency
20. Seminar/conference attendance
21. Impact of projects/activities
22. Class attendance
23. Midterm preparation 1
24. Midterm preparation 2
25. Note-taking
26. Listening in class
27. Discussion and interest
28. Flip-classroom usefulness
29. Previous cumulative GPA
30. Expected graduation GPA

## Dataset Observations

- The dataset contains 145 records.
- There are no missing values.
- The dataset contains categorical/integer-coded variables.
- STUDENT ID is an identifier and should not be used as a predictive feature.
- GRADE is the target variable.
- Feature selection will be performed before final model training.
